# ⚡ PowerAnalytics

## Overview
This project was built with a simple idea: make energy consumption easier to understand for everyone.

Many people don’t really know how much their daily habits impact their electricity costs. This application helps users simulate their expenses based on personal usage and see how common appliances affect their consumption.

It also uses real data (Eurostat, Numbeo) to give a more realistic view and allow comparisons between countries.

The goal is not just to show numbers, but to give practical insights that can actually help people save money and make better decisions in everyday life.

---

## Features
- Energy cost simulation based on personal data  
- Appliance consumption breakdown  
- Integration of real-world statistics  
- Simple and intuitive interface  
- Country-based comparisons  

---

## Tech Stack

- PostgreSQL
