# ⚡ PowerAnalytics

## Overview
This project was built with a simple idea: make energy consumption easier to understand for everyone.

Many people don’t really know how much their daily habits impact their electricity costs. This application helps users simulate their expenses based on personal usage and see how common appliances affect their consumption.

It also uses real data (Eurostat, Numbeo) to give a more realistic view and allow comparisons between countries.

The goal is not just to show numbers, but to give practical insights that can actually help people save money and make better decisions in everyday life.

---

## Features
- Energy cost simulation based on personal data  
- Appliance consumption breakdown  
- Integration of real-world statistics  
- Simple and intuitive interface  
- Country-based comparisons  

---

## Tech Stack
- Flask (Python)  
- PostgreSQL  
- HTML, CSS, JavaScript  

---

## Purpose
I believe technology should be useful first.

This project is my way of using programming to solve a real problem: helping people understand and manage something that affects them every day.

## *Scalability & Extensibility
For simplicity, I decided to focus only on a few European countries (mainly the ones I live in or interact with), instead of covering the entire EU dataset.

However, the structure of the code allows it to be easily extended to all European countries without any major changes.

The backend is modular and designed to grow: new countries, new datasets or even new features can be added without rewriting the existing logic.

In short, this is not a limited project, but a solid base that can evolve into a much more complete system.
